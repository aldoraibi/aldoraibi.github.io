# aldoraibi.github.io

موقع يحيى الدريبي: كل أدواتي في صفحة واحدة، بالعربية والإنجليزية، بهوية «منتصف الليل».

## البنية

- `src/tools.py` — محتوى كل أداة بالعربية والإنجليزية وروابطها. **التعديل يكون هنا فقط.**
- `src/build.py` — يولّد كل الصفحات من `tools.py` (بلا مكتبات خارجية).
- `index.html` و`en/index.html` — الرئيسية.
- `tools/<الأداة>/` و`en/tools/<الأداة>/` — صفحة تفاصيل كل أداة، وفيها رابط التحميل المباشر.
- `assets/` — التنسيق، وسكربت الظهور الناعم، وخطوط ثمانية (woff2)، والأيقونات، وأيقونة الموقع.

## التحديث

</div>

```sh
python3 src/build.py
```

ثم commit. لا خطوط ولا سكربتات من مواقع خارجية.

## عدّاد الزيارات

الموقع يعدّ الزيارات وضغطات أزرار التحميل والمشاركة عبر GoatCounter، بلا كوكيز. الرمز في `src/build.py` (`GC_CODE`)، واللوحة على `https://<الرمز>.goatcounter.com`. الرقم الظاهر في أسفل الصفحة لا يظهر إلا إذا فُعّل خيار «Allow adding visitor counts on your website» في إعدادات GoatCounter.
